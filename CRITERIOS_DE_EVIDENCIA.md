# Sobre as evidências

Estes textos descrevem trabalhos reais, mas não são uma auditoria independente ou uma demonstração pública do código dos produtos.

Uso alguns termos com sentido preciso:

- **Simulado:** comportamento verificado com dados fictícios e, quando necessário, serviços substitutos (*mocks*).
- **Teste nativo isolado:** componente ou integração real executado em ambiente controlado. Não significa operação contínua em cliente.
- **Teste com processo real:** envolve execução e observação no sistema operacional ou aplicação, dentro de um cenário delimitado.
- **Em desenvolvimento:** há trabalho implementado ou experimentado, mas faltam verificações para considerar o produto concluído.

Os números históricos da MeuAmiguinho foram informados a partir da experiência na operação. Não foram auditados de forma independente para este portfólio e não devem ser confundidos com lucro ou resultado individual.

As descrições públicas omitem dados de clientes, credenciais, código proprietário e detalhes internos que não são necessários para entender as decisões.
